# The help shown by F6 in the terminal's menu. Plain ASCII, at most 60
# columns and 20 lines a page. A line of dashes starts a new page. Lines
# starting with # are left out.
KEYS IN A SESSION

2nd + ESC          back to the menu (diamond + ESC too)
diamond + letter   Ctrl + letter: C stop, D log out,
                   Z suspend, L redraw, I Tab (2nd + I:
                   Shift-Tab), space Ctrl-Space
MODE (shift+Hand)  Alt: the next key goes after an ESC
APPS Tab   CLEAR erase the line   LN search the history
diamond + up/down  Page Up / Page Down
diamond + l/r      a word back / forward (ESC B, ESC F)
Hand + arrows      Ctrl + arrows (shift + arrows: Shift)
2nd + up/down      Home / End (2nd + left/right too)
2nd + plus         a strip of symbols the keyboard lacks
F1 to F8           the function keys; diamond + F1 to F4
                   are F9 to F12
2nd + APPS         screenshot, saved on the computer
2nd + backspace    Insert; diamond + backspace: Delete
The divide key types /   Use the minus key for -
More keys, and the keys for tmux, on the next page.
----
MORE KEYS

diamond + APPS     Shift-Tab
diamond + CLEAR    resets this screen, then Ctrl-L
diamond + MODE     Ctrl-]
2nd + LN           Ctrl-_ (undo)
diamond + LN       Ctrl-\ (quits what Ctrl-C does not)
diamond + ^        Ctrl-^
2nd + ^            ~

TMUX: the prefix is TAN, or diamond + B
SIN / COS          the previous / next window
2nd + SIN          the list of windows
2nd + COS          the window before this one
2nd + TAN          a new window
diamond + SIN      a page back (copy mode; q leaves)
diamond + TAN      copy mode
diamond + COS      pastes what copy mode copied
Prefix then B hides the bar or shows it again.
----
THE MENU

F1 Serial      a shell on the computer, over USB.
               Run "make shell" there.
F2 SSH         over the ESP32's Wi-Fi, to one of up to 8
               hosts: F1 to F8 picks it. Logs in with the
               ESP32's key, or asks for the password.
F3 Wi-Fi       F1 to F4 picks the network to use.
F4 Settings    F1 Wi-Fi: up to 4 networks
               F2 SSH hosts: F1 to F8 picks the one to set
               F3 SSH key: makes one, kept in the ESP32
               F4 copies the key to a host, after asking
F5 Debug       local echo, test pattern, key codes.

The menu's bottom row shows the Wi-Fi state.
